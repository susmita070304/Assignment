DESCRIPTION:
I built this NextGen Dashboard as part of my journey in learning Next.js and Supabase integration. My goal was to create a clean, responsive student portal that tracks course progress, activity streaks, and system announcements in a way that feels both modern and professional.


WHAT I HAVE LEARNED:
During this project, I spent a lot of time working on:

Data Integration: Learning how to fetch and filter real-time data from Supabase to provide a personalized user experience.

Animation Logic: Experimenting with Framer Motion to create smooth, non-intrusive UI transitions and card effects that feel responsive to user interaction.

Code Optimization: I focused on keeping the codebase maintainable by moving away from complex functional chains toward more readable, procedural logic that is easier to debug as the project grows.

How to Run Locally
Clone the repository:
------------------------------------------------------------
Bash
git clone https://github.com/susmita070304/Assignment.git
------------------------------------------------------------
-------------------------------
**Install the dependencies:**
Bash
npm install
------------------------------

------------------------------
Run the development server:

Bash
npm run dev
------------------------------

Open [http://localhost:3000](http://localhost:3000) in your browser to view the dashboard.
